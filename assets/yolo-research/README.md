# YOLO research image credits

The images in this directory are resized or cropped copies of figures from open-access papers.

- `sla-yolo-fig6.webp`: Figure 6 from Yanxia Lyu et al., “SLA-YOLO—Enhancing YOLO for Tiny Defect Detection in Industrial Defect Scenes” (2026), [source](https://www.mdpi.com/2227-7390/14/11/1973), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Resized for web display.
- `welding-yolo-fig4.webp`: Figure 4 from Srujan Hrudhay Geddam, “Automated Welding Defect Detection Using YOLO: A Deep Learning Approach for Industrial Quality Assurance” (2026), [source](https://engrxiv.org/preprint/view/6685), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Cropped from the official PDF for web display.
- `dcue-yolo-fig18.webp`: Figure 18 from Jiajin Zhong, HongCheng Wang, and JiaLin Zou, “DCUE-YOLO: A Lightweight Model in Industrial Defect Detection” (2025), [source](https://www.researchsquare.com/article/rs-5790775/v1), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Cropped from the official PDF for web display.
- `aff-yolo-fig7.webp`: Figure 7 from Manas Mehta, “AFF-YOLO: A Real-time Industrial Defect Detection method based on Attention Mechanism and Feature Fusion” (2023), [source](https://www.researchsquare.com/article/rs-3449230/v1), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Resized for web display.
